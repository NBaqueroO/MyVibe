#  How to Execute

1. Open the repository in **Visual Studio Code** or your preferred IDE
2. Open a terminal
3. Run the following command and wait for the installation to finish:
```bash
   npm install
```
4. Start the development server:
```bash
   npm run dev
```
5. Click the URL shown in the terminal or open your browser and go to:
>**Note:** The port may vary if `8080` is already in use by another process.
